# Lab Equipment & Instrumentation Rules

## 1. Oscilloscope: FNIRSI DPOS350P
*   **Спільна земля (Common Ground):** Канали CH1 та CH2 мають спільну землю. Затискачі заземлення обох щупів МАЮТЬ бути підключені виключно до одного потенціалу, інакше відбудеться коротке замикання та згоряння материнської плати.
*   **Смуга пропускання та щупи:**
    *   **Режим 1X:** Смуга обмежена 5 МГц (через ємність кабелю).
    *   **Режим 10X:** Смуга розширюється до 350 МГц. Обов'язково перемикати фізичний тумблер на щупі та в меню осцилографа одночасно.
    *   **Режим 100X (Висока напруга):** Використовувати щуп 1:100 для високовольтних вимірювань (допуск входу BNC — 400V).
*   **Фільтрація:** Для аналізу завад на затворах (Gate) використовувати режим High-Resolution (цифровий фільтр 8-bit -> 16-bit) та апаратне обмеження 20 МГц / 150 МГц.
*   **Вбудовані інструменти:** Наявний 50MHz Signal Generator, Spectrum Analyzer (200K-350MHz) та Frequency Response Analyzer для побудови графіків Боде.

## 2. Power Supply: PowerOne + XY6020LV
*   **Специфікація:** Промисловий БЖ PowerOne (46–59V, 25A) + DC-DC перетворювач XY6020LV.
*   **Правило запуску (CC):** Завжди виставляти ліміт струму (Constant Current) на XY6020LV до підключення навантаження.
*   **Захист:** На плюсовій лінії тимчасово встановлено "супердіод". Суворо контролювати відсутність зворотних струмів при тестуванні індуктивних навантажень або акумуляторів до моменту реалізації кастомного захисту.

## 3. Digital Analysis: Saleae Logic 8-CH
*   Використовувати 8-канальний донгл із ПЗ Saleae Logic для захоплення та аналізу цифрових протоколів (I2C, 1-Wire, PWM).

## 4. Multimeters & Transistor Tester
*   Використовувати 3 мультиметри для паралельного моніторингу (напруга живлення, падіння на шунті, напруга затвора).
*   Завжди тестувати нові та демонтовані компоненти (MOSFET, діоди) на транзистор-тестері для перевірки $V_{GS(th)}$ та розпіновки перед монтажем.
